# Screenshots Directory

## 📸 Purpose
This directory contains screenshots of Bob 2.0 session summaries and interactions. These are **REQUIRED** for hackathon submission.

## 📋 What to Include

### Required Screenshots
1. **Bob Task Session Summaries**
   - Full session overview screens
   - Task completion summaries
   - Code change summaries

2. **Bob Interactions**
   - Complex problem-solving sessions
   - Architecture discussions
   - Multi-file operations
   - Code reviews and refactoring

3. **Repository Context Usage**
   - Bob understanding your codebase
   - System-wide changes
   - Cross-file references

## 📁 Naming Convention

Use descriptive names that indicate the session and feature:

```
bob-session-[number]-[feature-name].png
```

Examples:
- `bob-session-001-project-setup.png`
- `bob-session-002-api-implementation.png`
- `bob-session-003-database-integration.png`
- `bob-session-004-code-review.png`

## ✅ Screenshot Checklist

Before submitting, ensure you have screenshots showing:

- [ ] Initial project setup with Bob
- [ ] Bob understanding your full codebase
- [ ] Complex multi-file operations
- [ ] Architecture decisions with Bob
- [ ] Code review and refactoring sessions
- [ ] Problem-solving and debugging
- [ ] Final implementation review

## 📐 Technical Requirements

- **Format:** PNG or JPG
- **Resolution:** Minimum 1920x1080 (Full HD)
- **Quality:** High quality, readable text
- **Content:** Full context visible, not cropped snippets

## 💡 Tips

1. **Take screenshots during development** - Don't wait until the end
2. **Capture full context** - Show the entire Bob interaction
3. **Include timestamps** - If visible in the interface
4. **Show depth** - Demonstrate meaningful Bob usage, not just autocomplete
5. **Organize by feature** - Group related screenshots together

## ⚠️ Important Notes

- **Surface-level use won't cut it** - Show Bob doing real, complex work
- **Quality matters** - Blurry or incomplete screenshots may hurt your submission
- **Document everything** - More screenshots are better than too few
- **Link to sessions** - Reference these in your `/bob-sessions/` documentation

## 📝 Example Screenshot Descriptions

When documenting screenshots in your session files, include:

```markdown
### Screenshot: bob-session-001-project-setup.png
- **What:** Initial project structure discussion with Bob
- **Shows:** Bob analyzing requirements and suggesting architecture
- **Key Points:** Full repository context, multi-file awareness
```
