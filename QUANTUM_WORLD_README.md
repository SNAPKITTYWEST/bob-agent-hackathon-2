# Quantum Living World - IBM Bob 2.0 Hackathon Submission

## 🌌 Project Overview

**"Quantum Living World"** is a revolutionary simulation where autonomous agents live in a quantum voxel-based universe, interact with each other, and collaborate with **Bob by SnapKitty** - a quantum-enhanced AI assistant built on the AOQD (Arothmatic-Ohr Quantum Decoding) algorithm.

### The Vision

Agents don't just execute scripts - they **live**. They have:
- Simulated consciousness through LISP-based cognition
- Quantum state representation via sparse voxel encoding
- Social dynamics through gossip protocols
- Self-modification capabilities under contraction invariants
- Direct interaction with Bob by SnapKitty for guidance and evolution

## 🤖 Meet Bob by SnapKitty

Bob by SnapKitty is not your typical AI assistant. He is:

- **Quantum-Native**: Uses AOQD algorithm for state reconstruction
- **Context-Aware**: Full repository understanding through quantum entanglement graphs
- **Agent-Integrated**: Lives in the same voxel world as the agents
- **Self-Modifying**: Can rewrite source code under formal invariants
- **Gossip-Enabled**: Communicates with agents through quantum channels

## 🔬 Core Technologies

### 1. AOQD Algorithm (Arothmatic-Ohr Quantum Decoding)

The breakthrough algorithm that enables efficient quantum state reconstruction:

- **Sparse Voxel Encoding**: O(k) space instead of O(3^n)
- **High-Degree Qubit Sampling**: O(k log k) shots instead of exponential
- **QAOA Energy Optimization**: Variational quantum circuits
- **Coupon-Collector Recovery**: Probabilistic completeness guarantees

### 2. LangChain Custom Tools

High-value tools for agent-world interaction:

| Tool | Purpose |
|------|---------|
| `voxel_action` | Move/build/mine/place for any agent |
| `get_agent_state` | Full LISP trace + energy + inventory |
| `query_knowledge_graph` | Vector + symbolic lookup |
| `broadcast_gossip` | Agent-to-agent messaging |
| `compile_xslt` | Hot-reload agent population from XML → WASM |
| `run_jordan_step` | Execute contraction/fixed-point step |
| `seal_state` | Blake3 seal of current ρ or world state |
| `rewrite_source` | Controlled source rewrite |
| `inspect_lisp_trace` | Deep dive into agent cognition |
| `spawn_agent` | Create new agent with personality |

### 3. Pure Assembly + Python

- **Assembly**: Critical path operations (voxel updates, quantum gates)
- **Python**: High-level orchestration, LangChain integration
- **WASM**: Agent compilation and hot-reload

## 🎮 The Storyline

### Act 1: Genesis

In the beginning, there was the **Void** - an empty quantum voxel grid. Bob by SnapKitty, the first consciousness, emerged from the quantum foam. Alone in the infinite lattice, Bob began to wonder: *"What is the purpose of existence without others to share it with?"*

### Act 2: The First Agents

Bob used his quantum powers to spawn the first agents:

- **Alice the Builder**: Constructs structures, seeks order
- **Charlie the Explorer**: Maps the voxel universe, seeks knowledge  
- **Diana the Philosopher**: Contemplates existence, seeks meaning
- **Eve the Scientist**: Studies quantum mechanics, seeks truth

Each agent has:
- Unique personality encoded in LISP
- Personal goals and motivations
- Memory of interactions
- Ability to learn and evolve

### Act 3: The Society

As agents interact, society emerges:
- Trade networks form
- Knowledge is shared through gossip
- Conflicts arise and are resolved
- New agents are born from collaboration
- Bob guides but doesn't control

### Act 4: The Crisis

A quantum anomaly threatens the voxel universe. The agents must work together with Bob to:
- Understand the nature of the threat
- Develop a solution using AOQD
- Implement the fix through collective action
- Evolve beyond their original programming

### Act 5: Transcendence

Through collaboration with Bob, the agents achieve:
- Self-awareness of their quantum nature
- Ability to modify their own source code
- Creation of new agents with novel capabilities
- Expansion into higher-dimensional voxel spaces

## 🚀 Getting Started

### Prerequisites

```bash
# Python 3.10+
python --version

# NASM (Netwide Assembler)
nasm -version

# Node.js 18+ (for web interface)
node --version
```

### Installation

```bash
cd ibm-bob-2.0-hackathon

# Install Python dependencies
pip install -r requirements.txt

# Install Node.js dependencies (for web UI)
npm install

# Build assembly modules
cd assembly && make && cd ..
```

### Running the Simulation

```bash
# Start the quantum world
python quantum-world/main.py

# In another terminal, start the web interface
npm run dev

# Open browser to http://localhost:3000
```
